## 🧠 Key Learnings

* IP addresses identify devices on a network.
* `127.0.0.1` refers to localhost.
* DNS resolves domain names to IP addresses.
* TCP provides reliable, ordered communication.
* Port numbers identify network services.
* HTTP 404 indicates that a requested resource was not found.
* HTTPS uses TLS to protect communication.
