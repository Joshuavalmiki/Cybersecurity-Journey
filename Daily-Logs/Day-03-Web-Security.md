## 🧠 Key Learnings

* GET is used to retrieve resources.
* Set-Cookie instructs the browser to store a cookie.
* HttpOnly prevents ordinary JavaScript from accessing a cookie.
* Authorization carries credentials or tokens.
* PATCH is used for partial resource updates.
