## 📚 Topics Learned

### 1. Basic Linux Commands

* `pwd` — Display current directory
* `ls` — List files and directories
* `ls -la` — Show all files with detailed information
* `mkdir -p` — Create directories

### 2. File Permissions

* Understanding Read (r), Write (w), Execute (x)
* Permission values: 4, 2, 1
* `chmod 600`
* `chmod 644`

### 3. Users and Privileges

* `whoami`
* `id`
* `id -u`
* `id -un`
* `sudo -l`

### 4. Process Management

* `ps`
* `ps aux`
* `top`
* Background processes using `&`
* Finding and terminating processes using `kill`

## 🧠 Key Learnings

* Linux permissions control who can read, write, or execute files.
* `sudo` provides elevated privileges for a command.
* A process runs with a Process ID (PID).
* `ps aux` displays running processes.
* `top` provides live process monitoring.
* Using `sudo` for one command does not permanently change the current shell user.
